# Парсер выдачи Авито — Geonode

Публичная ссылка: https://avito-prodvizhenie-checker.onrender.com

## Назначение

Пользователь вставляет URL поисковой выдачи Авито, нажимает «Анализировать», получает количество объявлений на первой странице, число с явно обнаруженными признаками платного продвижения и число карточек с неизвестным статусом.

Используется Geonode Scraper API: POST https://scraper.geonode.io/v1/extract, formats [html], processing_mode sync, render_js true. Бесплатный тариф на момент разработки — 1500 запросов/месяц, без карты, условия уточнять на geonode.com/pricing.

## Подключение (однократно для владельца)

1. Зарегистрировать бесплатный аккаунт на https://app.geonode.com/scraper-api (вручную подтвердить регистрацию, если сервис потребует).
2. На странице Scraper API нажать Get Code → API & Integrations → Copy API Key.
3. В Render открыть web service avito-prodvizhenie-checker → Environment → Add Environment Variable.
4. Key: GEONODE_SCRAPER_API_KEY, Value: скопированный секретный ключ. Сохранить, дождаться перезапуска.
5. Открыть https://avito-prodvizhenie-checker.onrender.com/api/health и проверить configured:true. Это не отправляет запросы Geonode.
6. Выполнить первый реальный тест по поисковой выдаче Авито. Сверить выборку и признаки продвижения с открытой страницей.

Никогда не публиковать API-ключ в коде, GitHub, форме на сайте, документации или сообщениях.

## Безопасность расходов и корректность

- Проверки для одинакового URL кэшируются на 15 минут и объединяются, если поступили одновременно.
- Ограничение 40 внешних обращений за календарные сутки (GEONODE_DAILY_LIMIT). Render free может перезапускаться, так что это не абсолютно жёсткий лимит за месяц. Поставщик сам ограничивает Free-план.
- API принимает только HTTPS URL c доменом avito.ru и приводит проверку к первой странице, удаляя p/page.
- Сервер не выводит в браузер ключ и не сохраняет HTML ответов в файлах.
- Если распознать данные карточек или определить признаки продвижения нельзя, результат маркируется как неполный либо выдаётся ошибка. Точные цифры до проверки на реальной выдаче не гарантируются.
- Надпись «Реклама» не равна продвижению карточки.

## Разработка

Сервис Node.js без сторонних библиотек. `npm test` — проверка синтаксиса и формы. `npm start` — запуск HTTP сервера. Исходники `server.js`, `index.html` и `test-site.js`.

Независимый проект, не связанный с Авито.
