# Бесплатный анализ продвижения Авито

Сайт: https://avito-prodvizhenie-checker.onrender.com

**Версия 1.1: кнопка-закладка для браузера.** Работает без аккаунтов, API-токенов, платных сервисов и серверных запросов к Авито. Признаки продвижения анализируются прямо в браузере пользователя.

## Инструкция для посетителя

1. Откройте сайт с компьютера в Chrome/Edge.
2. Нажмите Ctrl+Shift+B, чтобы показать панель закладок.
3. Перетащите красную кнопку «Посчитать продвижение» на панель закладок.
4. Откройте нужную поисковую выдачу Авито (можно через поле ссылки на сайте).
5. Нажмите свою закладку — появится окно с количеством карточек, явными признаками продвижения и неизвестными статусами.
6. При желании нажмите «Прогрузить карточки», затем «Пересчитать».

Ничего не устанавливается. Сама кнопка не отправляет данные о выдаче на наш сайт, не обходит CAPTCHA/ограничения сервера.

## Что считается

Явная метка «Продвинуто»/«Продвигается», атрибуты карточки или доступный флаг isPromoted для конкретного объявления.

При невозможности определить статус карточка записывается как «Без подтверждения статуса». Продвижение не всегда видно извне, поэтому счётчик подтверждённых признаков — не гарантированное количество всех продвигаемых объявлений.

## Разработка

- bookmarklet.js — скрипт, запускаемый на странице Авито.
- index.html — сайт-инструкция и ссылка для перетаскивания.
- GET /api/bookmarklet — выдача однострочного скрипта для закладки.
- Node.js 20+: npm install, npm test, npm start.
- Render: build npm install && npm test; start npm start.

Маршруты POST /api/check и POST /api/check-html оставлены для дальнейшего развития, но не нужны в бесплатном режиме. Прямые серверные запросы к Авито могут блокироваться HTTP 403. Платная интеграция с Apify не включена.

Независимый проект, не аффилирован с Авито.
