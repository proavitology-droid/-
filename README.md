# Проверка продвижения Авито — бесплатная версия по скриншотам

Публичный адрес: https://avito-prodvizhenie-checker.onrender.com

## Для пользователя

1. Откройте первую страницу выдачи Авито в браузере или мобильном приложении.
2. Сделайте длинный скриншот выдачи либо несколько скриншотов без повторения объявлений.
3. Откройте сайт на телефоне или компьютере, загрузите скриншоты (до 8) и нажмите «Проверить продвижение».

Сервис на устройстве пользователя при помощи Tesseract.js (OCR) обнаруживает видимые надписи «Продвинуто»/«Продвигается» и отдельно «Реклама». Изображения не отправляются на наш сервер. Для загрузки движка распознавания и словарей используется публичный CDN. Официальные данные Авито по платному продвижению не используются.

## Принципиальные ограничения

- Скриншоты не дают полного и точного числа всех платно продвигаемых объявлений: Авито может не отображать соответствующую метку.
- Распознавание текста может пропустить мелкий шрифт или ошибочно распознать слова.
- Надпись «Реклама» учитывается отдельно и не суммируется с «Продвинуто».
- Если на скриншотах пересекаются одни и те же карточки, подсчёт может продублировать отметки.
- Для проверки первой страницы нужны скриншоты всей страницы, а не только первого экрана.
- Автоматическая проверка только по ссылке не поддерживается в бесплатном режиме, поскольку сервер получает HTTP 403 при прямом запросе на Авито.

## Техническая часть

- HTML/CSS/JS: index.html.
- Tesseract.js 5.1.1 (русский + английский), распознавание на клиенте.
- Бэкенд Node: server.js, отвечает за раздачу страницы и необязательные старые маршруты API.
- Тесты: npm test. Запуск: npm start.
- Старый эксперимент с кнопкой-закладкой сохранён в bookmarklet.js, но не показывается пользователям.
- В Render не установлен платный API-токен. Платные запросы к Apify не выполняются.

Независимый проект, не аффилирован с Авито.
