# Парсер выдачи Авито

Первая версия: счётчик признаков платного продвижения на первой странице поисковой выдачи Авито по ссылке. Сервис показывает только данные, которые смог подтвердить; отсутствие доступа к Авито и неполные результаты обозначаются отдельно.

Независимый проект, не официальный сервис Авито.

## Автоматический режим по ссылке

Прямые запросы Render → Avito блокируются HTTP 403 (проверено при запуске 10.11.2026). Поэтому без внешнего поставщика сервис показывает ошибку, а не выдумывает число.

Для автоматического режима реализована **необязательная** интеграция с Apify Actor `dami_studio/avito-listings-scraper`. Этот актор документирует `isPromoted` и работу с поисковыми URL. В запрос передаются `maxPagesPerSearch: 1`, `maxItems: 50` и `localOnly: false` для анализа первой страницы в исходном порядке без скрытого геофильтра. Стоимость по тарифу актора на 10.11.2026 — около $0.30 за 1 000 объявлений, то есть ориентировочно $0.015 за 50.

Для включения нужно завести аккаунт Apify, проверить юридические условия сервиса и тариф, получить токен в разделе `API & Integrations`, затем в Render > Environment добавить секретную переменную `APIFY_TOKEN`. Токен нельзя помещать в HTML или публичную форму. Установите `APIFY_DAILY_LIMIT`, чтобы ограничить число проверок в сутки (по умолчанию 20 на запущенный экземпляр). Без токена публичная форма показывает понятное уведомление и предлагает режим сохранённого HTML. Платный источник не запускается до установки токена.

Исходный анализ HTML остаётся доступным для сохранённой страницы. Сервис возвращает частичный результат, если отсутствуют сведения о продвижении некоторых объявлений.
