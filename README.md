# Парсер выдачи Авито

Первая версия: счётчик признаков платного продвижения на первой странице поисковой выдачи Авито по ссылке. Сервис показывает только данные, которые смог подтвердить; отсутствие доступа к Авито и неполные результаты обозначаются отдельно.

Независимый проект, не официальный сервис Авито.

## Автоматический режим по ссылке

Прямые запросы Render → Avito блокируются HTTP 403 (проверено при запуске 10.11.2026). Поэтому без внешнего поставщика сервис показывает ошибку, а не выдумывает число.

Для автоматического режима реализована **необязательная** интеграция с Apify Actor `nice_dev/avito-listings-scraper`. Для её включения нужно самостоятельно создать аккаунт поставщика, проверить юридические условия и тариф, затем добавить **секретную** переменную `APIFY_TOKEN` в Render > Environment (никогда не вставлять токен в код или в публичную форму). Дополнительно можно ограничить количество платных проверок переменной `APIFY_DAILY_LIMIT` (по умолчанию 20 за сутки на сервер). Без токена API Apify не запускается, платные расходы не возникают.

Исходный анализ HTML остаётся доступным для сохранённой страницы. Сервис возвращает частичный результат, если отсутствуют сведения о продвижении некоторых объявлений.
